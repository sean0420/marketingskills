# Shine 디자인 시스템 (v6~)

## 콘셉트

책상 옆 iPad 위젯. 은은한 오로라 배경 위에 반투명 유리 카드를 벤토 그리드로 배치한다. Shine의 상징인 일출 그라데이션은 꼭 필요한 곳에만 쓴다.

## 색

| 토큰 | 라이트 | 다크 | 쓰임 |
|---|---|---|---|
| 배경 | #F1F2F6 | #0A0B0F | 바탕 |
| 글자 | #15161C | #F2F2F6 | 본문 |
| 보조 글자 | #696C7B | #9A9DAE | 메타, 라벨 |
| 일출 그라데이션 | #FFB547 → #FF6A3D → #FF4D8D | 동일 | 로고, 시계, 기본 버튼, 지금 선, 오늘 날짜, 중요 배지 |
| 업무 | #3B6CFF | #7E9CFF | 업무 일정·체크 |
| 개인 | #0B9E70 | #3FD8A6 | 개인 일정·체크 |
| 경고 | #E5484D | #FF6B70 | 지난 마감, 급한 메일 |
| 오로라 | 피치 #FFD2B3, 라일락 #DCD4FF, 민트 #C5F0DD | 짙은 버전 | 배경 번짐 |

## 글꼴

- Geist: 숫자, 영문, 시계
- IBM Plex Sans KR: 한글 본문
- 인사말 34px / 흐름 제목 20px / 카드 제목 16px / 본문 14px

## 레이아웃

| 화면 | 구성 |
|---|---|
| iPad 가로 (1100px 이상) | 인사말·시계 / 입력창 / 숫자 요약 4개 / 왼쪽: 오늘의 흐름, 오른쪽: 중요한 일 · 할 일 · 메일 · 최근 메모. 주·월 보기에서는 흐름 카드가 전체 폭 |
| iPad 세로 (700~1099px) | 흐름 카드 전체 폭, 아래에 할 일과 메일 2열 |
| 핸드폰 (699px 이하) | 숫자 요약 → 중요한 일 → 할 일 → 메일 → 흐름. 편집 창은 아래에서 올라오는 시트 |

## 규칙

- 카드 모서리 28px(핸드폰 22px), 버튼 14px, 칩 9px
- 업무와 개인은 색으로만 구분하고, 카드 왼쪽 세로 막대는 쓰지 않는다
- 입력칸 글자는 핸드폰에서 16px 이상 (아이폰 자동 확대 방지)
- 날짜·시간 입력칸은 `appearance:none` + `width:100%` (아이폰 넘침 방지)
