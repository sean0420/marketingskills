# 01. 기획 요약

원본 기획서: https://claude.ai/artifact/8Tr8DEyKPyK8P8LLbVACsM (2026-11-16 작성)

## 한 줄 정의

"적기만 하면 정리되는" 나만의 업무 비서.

## 왜 만드는가

- 미팅, 이메일, 아이디어가 캘린더, 메모앱, 머릿속에 흩어져 놓치는 일이 생긴다.
- 업무(GloZ 영업, 파트너, 투자자)와 개인 일정을 따로 보거나 합쳐 볼 수 있어야 한다.
- 기록이 귀찮으면 결국 안 쓴다. 입력은 3초 안에 끝나야 한다.

## 목표, 비목표, 실패 조건

| 구분 | 내용 |
|---|---|
| 목표 | 한 줄 입력으로 일정과 할 일이 자동 등록된다 |
| 목표 | 업무 / 개인을 필터 한 번으로 나눠 보거나 합쳐 본다 |
| 목표 | 미팅 메모를 붙여넣으면 후속 액션과 마감일을 뽑아준다 |
| 목표 | iPad, PC, 핸드폰 어디서든 접속된다 |
| 비목표 | 팀 협업 툴 (1인용) |
| 비목표 | CRM 대체 (딜 파이프라인은 기존 툴 유지) |
| 비목표 | Google Calendar 기능 전부를 다시 만드는 것 |
| 실패 조건 | 입력이 귀찮아서 안 쓰게 된다 |
| 실패 조건 | AI가 날짜를 잘못 읽어 일정을 믿을 수 없다 |
| 실패 조건 | 기존 캘린더와 따로 놀아 두 곳에 적어야 한다 |

## 구축 방식 결정

| 방식 | 장점 | 단점 | 결정 |
|---|---|---|---|
| A. claude.ai 앱 | 로그인, DB, AI, 음성, 커넥터가 이미 있음. 서버·API 키 불필요 | claude.ai 로그인 필요, 푸시 알림 제한 | **채택** |
| B. 자체 웹앱 (Next.js + Supabase + Claude API) | 내 도메인, PWA, 푸시 알림 | 로그인·DB·AI·OAuth 직접 구축, 유지보수 | 필요 시 4단계에서 전환 |
| C. Notion + AI 자동화 | 코딩 거의 없음 | 한 줄 입력 자동 파싱이 어색함 | 제외 |

## 확정된 사항

| 항목 | 결정 |
|---|---|
| 이름 | Shine (비서 이름이자 앱 이름) |
| 메인 기기 | iPad, 항상 옆에 둠. PC와 핸드폰은 보조 |
| 메일 | 업무, 개인 모두 Gmail. 커넥터는 업무 계정(glozinc.com) 연결. 개인 메일은 업무 계정으로 자동 전달 후 주소로 구분 |
| 캘린더 | 미팅은 Google Calendar가 원본. 할 일, 메모, 개인 일정은 Shine이 원본 |
| 위치 | 달라스 (America/Chicago). 해외 시간대 미팅은 상대 시간대로 생성 |
