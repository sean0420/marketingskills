| 기능 | 내용 | 메모 |

| 아침 자동 브리핑 (백그라운드) | 앱을 열지 않아도 매일 아침 메일·일정을 미리 정리 | 예약 작업으로 구현 가능 |
| Google 캘린더 읽기 동기화 | 상대가 보낸 초대 등 기존 미팅을 Shine 타임라인에 표시 | `list_events` 연동 |

| 사람·회사 타임라인 | "Netflix" 누르면 관련 미팅, 할 일, 메일을 시간순으로 | |
